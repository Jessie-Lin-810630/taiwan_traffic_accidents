# ADR-0020：縣市地區歸屬統一為單一原則

- 日期：2026-08-27
- 狀態：已採納
- 範圍：`src/task/e_crawling_nightmarket.py`、`src/task/core/c_data_service.py`、
  `src/pages/v_act1_all_accident.py`、`src/pages/v_act1_city_accident.py`
- 相關：
  [ADR-0009 預計算的查詢粒度以批次為單位](./0009-預計算的查詢粒度以批次為單位.md)
- 來源：使用者於 2026-08-27 提出，希望把散在四支腳本的地區分法收斂成一套

## 名詞

| 詞 | 意思 | 在程式碼的哪裡 |
| --- | --- | --- |
| **地區** | 五個區之一，夜市與事故統計的分組單位 | `fact_night_markets.region` 欄、前端的 `region` 欄 |
| **縣市層級歸屬** | 以縣市名稱查表得到地區 | `cities_per_region`、`region_map` |

## 背景

關於「這個縣市屬於哪個地區」，在以下四支腳本各寫一套規則，但分法卻互不相同：

| 在哪 | 用途 | 宜蘭縣歸在 | 澎金馬那一組叫 |
| --- | --- | --- | --- |
| `e_crawling_nightmarket.cities_per_region:45-51` | d05 抓取時決定寫進 MySQL 的 `region` 欄 | 東部 | 離島 |
| `v_act1_all_accident.cities_per_region:39-45` | 全臺頁熱力圖的縣市篩選 | 東部與東部離島 | 其他離島 |
| `v_act1_city_accident.region_map:109-131` | 縣市頁的地區欄計算 | 北部 | 離島 |
| `v_act1_city_accident.REGION_ORDER:26` | 縣市頁地區下拉選單的顯示順序 | 東部與東部離島 | 離島 |

由此產生兩個實際的問題：

**問題 1：同一個宜蘭夜市在兩個頁面被分到不同地區。** 全臺頁算進「東部與東部離島」，
縣市頁算進「北部」，兩頁的地區統計對不起來。

**問題 2：全臺頁選「離島」會靜默篩不出任何縣市。** 該頁的 radio 選項寫的是
`"離島"`（`v_act1_all_accident.py:506`），但該頁的變數 `cities_per_region` 卻命名為
`"其他離島"`。這導致 `get_region_or_cities(region="離島")` 函式會回傳空字串，導致熱力圖是空的。


## 決策

### 一、統一本專案對五個地區的定義

| 地區 | 縣市 | 附屬離島 | 四支腳本原本一致 |
| --- | --- | --- | --- |
| 北部 | 臺北市、新北市、基隆市、桃園市、新竹市、新竹縣、**宜蘭縣** | 無 | N |
| 中部 | 臺中市、苗栗縣、彰化縣、南投縣、雲林縣 | 無 | Y |
| 南部 | 臺南市、高雄市、嘉義市、嘉義縣、屏東縣 | 無 | Y |
| 東部與東部離島 | 花蓮縣、臺東縣 | **蘭嶼、綠島** | N |
| 其他離島 | 澎湖縣、金門縣、連江縣 | **琉球** | N |

最後一欄記的是這個地區在四支腳本裡原本是否同名同成員。三個 N 各差在：
北部與東部與東部離島差在宜蘭縣歸誰，其他離島差在名稱是「離島」還是「其他離島」。

- 「其他離島」的完整語意是「排除東部之其他離島」，在程式碼與資料庫一律使用短名
「其他離島」，使其能安全落在 `fact_night_markets` 表的欄位 `region` 之型別 `VARCHAR(10)`。

- 宜蘭縣歸北部，是基於臺灣現行行政區劃分，沒有其他原因，本決策遵照政府規定。

### 二、附屬離島的拆成兩組分類

```python
琉球       -> 其他離島
蘭嶼、綠島  -> 東部與東部離島
```

### 三、不動 mart 層的事故分區

`src/task/mart_table_sql/analysis_overview_pedestrian_accidents.sql:100-105`
另有一份以經緯度切分的 `region`，標的是事故發生點而非夜市，且全專案沒有下游讀取者：
縣市頁拿到總表後以 `df["region"] = df["city"].map(region_map)` 直接按照決策一的標準統一。

## 後果

### 正面

- 一個縣市在全專案只有一個地區，全臺頁與縣市頁的地區統計可以互相對照
- 全臺頁的「離島」選項會正常篩出澎湖、金門、連江與琉球

### 負面

- 地區的定義仍然分散在四支腳本，本次統一的是內容而不是位置。

### 中性

- 五個地區的數量與名稱不變，前端版面與圖表不需調整
